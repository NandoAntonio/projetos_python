# Desafio em Python - (Loja Gamer)

## 🎮 Loja Gamer - Sistema de Gerenciamento de Estoque e Vendas

Projeto desenvolvido em Python com o objetivo de aplicar na prática os conceitos de Programação Orientada a Objetos (POO), por meio da construção de um sistema de gerenciamento para uma loja de produtos gamers.

Este projeto faz parte da minha evolução nos estudos de desenvolvimento de software e representa uma oportunidade de transformar conhecimentos teóricos em uma aplicação funcional.

## 🚀 Sobre o Projeto

A Loja Gamer é um sistema executado pelo terminal que permite gerenciar produtos, clientes, estoque e vendas.
A aplicação foi desenvolvida utilizando classes e métodos para organizar as responsabilidades do sistema, buscando aplicar boas práticas de programação e tornar o código mais estruturado e reutilizável.

## ⚙️ Funcionalidades

* Cadastro de Produtos: permite cadastrar produtos comuns, controles e teclados.

* Gerenciamento de Estoque: permite adicionar e remover quantidades de produtos.

* Busca de Produtos: pesquisa produtos cadastrados.

* Cadastro de Clientes: registra clientes e seus dados.

* Realização de Vendas: associa produtos e clientes, atualizando automaticamente o estoque.

* Histórico de Vendas: consulta as vendas realizadas.

* Cancelamento de Vendas: permite cancelar uma venda e devolver os produtos ao estoque.

* Controle de Compras: consulta o histórico de compras e o total gasto por cliente.

* Relatórios Financeiros: apresenta o faturamento total e o valor dos produtos em estoque.

## 🧠 Tecnologias e Conceitos

* **Linguagem:** Python

* **Estruturas:** Programação Orientada a Objetos (POO), Métodos, Listas, Laços de Repetição, Condicionais e Funções, Propriedades (@property), Getters e Setters, Exceções (try, except, raise).
Ferramentas: Git e GitHub para controle de versão.

## 🎯 Objetivo de Aprendizado

O principal objetivo deste projeto é consolidar os fundamentos de Python e Programação Orientada a Objetos, desenvolvendo uma aplicação que simula operações básicas de uma loja.
